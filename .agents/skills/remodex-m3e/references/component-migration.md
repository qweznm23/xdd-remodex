## fix95 自定义字体

外观页使用系统文档选择器分别导入界面和助手正文的 TTF/OTF，支持独立恢复默认。主题加载本机保存的字形，聊天的行内代码和代码块使用随包提供的 JetBrains Mono。API 35 独立测试包通过系统选择器导入静态 OTF 和两种可变 TTF；取消和替换失败后保留原字体。深色聊天在进程重启后，界面和正文字形的实测宽度均匹配各自的导入文件；代码中的字母与数字等宽。已逐项恢复并再次启动验证。正式包按散列核对了 JetBrains Mono 字体及 OFL 许可证。

## fix98 活动详情滚动

活动详情直接使用时间线已经划分的条目和标识。旧路径在一个含 13 个显示分段的长消息上生成了 169 项；回归用例核对修复后 13 项的数量、顺序和标识。弹层仍使用 ModalBottomSheet，文本、命令和文件共用一个带内容类型的 LazyColumn；分组展开时只布局可见行。列表外的普通聊天沿用原渲染路径。

API 35 的独立 Release 测试包通过真实聊天入口打开详情。从长文本第 1 段滑到第 100 段；展开了 40 条命令，从首项滑到末项再收起；暗色下验证内容滚动、下拉关闭和返回正文后的行坐标。

## fix99 聊天输入栏的模型选择

已有会话与新会话草稿共用模型选择底部弹层。原生单选行展示服务端返回的模型，快速模式使用 Switch，推理强度使用 M3 Slider 并定制胶囊填充。常规竖屏下列表单独滚动，推理控件位于弹层底部。窗口高度不足时整张内容可以滚动。拖动预览当前档位，松手提交一次。保存失败时弹层显示原始错误。

API 35 独立 Release 包用模拟仓储从聊天输入栏进入，覆盖 35 个模型、不同推理档位、保存被拒后重选、键盘草稿、横屏、浅深色、自选色和 1.5 倍字体。长列表滚动前后核对了滑块坐标，使用测试仓储的写入记录核对每次拖动只提交一次。未做真实账号模型切换或 TalkBack 人工朗读验收。

## fix100 模型列表高度与滚动

常规竖屏下模型列表最高 180 dp，小窗口继续允许滚动到底部操作区。每行保留至少 48 dp 点击范围和原生单选语义，模型说明收为一行。列表按模型 ID 复用行，重新打开时定位当前选项。

在同一 API 35 模拟器、35 个测试模型下，列表滚动区域由 1228 px 缩为 398 px，底部滑块坐标保持一致。两版各做三轮相同滑动，gfxinfo 的第 95 百分位耗时分别为 11–12 ms 和 10–13 ms，均未复现严重掉帧。另用带长说明的列表验证靠后选项、重开定位，以及浅色、深色、自选色、1.5 倍字体、横屏和键盘草稿。未测用户真机。

## fix101 聊天输入栏和文字

照片、输入、语音与发送共用主操作行；模型、计划状态和更多操作单独占一行。阅读时收起工具行，保留单行草稿。高度变化与透明度分开过渡，系统动画倍率生效。编辑时换行直接按文本实测高度排版。

从参考 APK 的 azb.b 沿 p9b.a、b9b.invoke 追到 e9b.invoke，编辑器读取字体样式 x19.g 并覆盖前景色。该样式采用 17 sp、400 字重、1.4 em 行高。输入、提示与收起后的草稿使用同一套正文排版，沿用已选界面字体，浅色提示取接近截图的暖灰。排版和前景色适用于深色、种子色和大字体。FlClash 的 scaffold_search.dart 中 _SearchMove.at 将内容淡入与形状增长分开，本项目按聊天区的空间选用了 220 ms 展开、160 ms 收起。

API 35 独立 Release 包验证了中英文与数字、IME 组词和提交、多行草稿、收起再编辑、发送及停止、模型选择、深浅色、1.5 倍字体和系统关闭动画。通过录屏检查收放过程具有中间帧；在流式消息到达时核对阅读位置。未在用户真机上实测。

另通过系统文件选择器将参考 Sans 导入独立测试包的「界面字体」，重启测试进程后验证中文、英文、数字输入。公开 APK 使用项目现有字体策略。

## fix102 阅读态回复栏

Claude Android 参考包中，编辑器装饰层 e9b → o9b → up8 把当前提示交给 yzc.a。它使用 x19.g 的 17 sp、400 字重、1.4 em 行高，单独覆盖 nga.B 提示色。普通暖色主题的浅色、深色值分别追到 #7B7974 与 #97958D。Remodex 的浅色取 #777570，使白底小字满足 4.5:1；深色使用 #97958D。Remodex 将收起的草稿作为摘要处理，展开编辑时使用正文字色。

参考图中的圆盘、边距、描边与阴影按截图测量。回复栏左右留 16 dp，收起时通常高 52 dp，操作区按 48 dp 排列，圆盘直径 36 dp。使用 M3 图标按钮和 Surface，附件沿用单击、长按语义。装饰边线与键盘焦点描边分别配色。浅色上沿由模拟器旧版的 #A5A9B2 改为 #E7E7E5，与参考图采样相符。同宽 586 px 对齐后，“回复”首笔横坐标为参考 121 px、fix101 126.2 px、fix102 121.3 px。参考字形高约 24 px，模拟器为 26 px，原手机系统字号和字库未核实。

API 35 独立 Release 测试使用 360 dp 宽度验证浅深色、空提示、已有草稿及重开编辑；在默认模拟器宽度验证中文组词、提交、发送、停止、关闭动效、1.5 倍字体和自选色。大字体下，从发送圆盘中心外侧 21 dp 触摸，再回到最新消息，验证发送的草稿进入时间线。设备未运行 TalkBack，未在用户真机实测。

## fix103 输入栏附件动作与收放

输入栏共享一个 48 dp 的「+」触控区。收起时与摘要同排，展开时在模型按钮左侧。M3 动作菜单锚定这个按钮，可在两种状态下长按打开，单击仍调用照片选择器。工具行展开高度、编辑文字的起始留白与模型按钮的位置使用同一个 Compose Transition。系统关闭动画时直接进入目标布局。

API 35 独立 Release 测试验证已有会话的两态布局、两处长按、菜单返回、单击照片与系统文件选择、切换模型、深色菜单、收起再展开保留中文和英文草稿。逐帧检查了展开过程。另以 1.5 倍字体、自选色及关闭动画验证布局和长按。未测用户真机和 TalkBack。新建会话草稿页复用此布局，该页原有的附件回调为空。

## fix104 首条附件、建议回复和启动窗口

新建草稿与现有会话共享「+」入口、系统选择器、相机权限、上传进度和重试。照片作为图片项发送，文件作为已上传路径写入该轮消息。首条发送被拒后复用已创建的会话，保留草稿和附件。API 35 模拟器从系统相册和文档选择器取文件，以测试仓库核对混合发送、无文字发送及拒绝后重试。系统拍照 Activity 已被调用，此模拟器报告零个摄像头，未验真机拍摄。

建议回复采用与编辑器对齐的中性卡片、原生操作按钮和全文底部弹层。浅深色下检查三行截断、展开、手动填入与收起。设置、设备及侧栏共用阅读背景和卡片颜色，主题种子继续用于操作与选择状态。启动窗口以日夜资源提供阅读背景，API 31 以上显式指定系统启动画面的底色与应用图标。API 35 冷启动录像和浅色页面截图取样已验证；未验其他系统版本的启动动画。

## fix106 建议入口和输入栏停止按钮

当前会话有建议时，在输入栏文字行右侧显示灯泡，阅读态、键盘弹出与已有草稿均可打开全文。没有结果或采纳后移除按钮及其槽位。自动收起仅控制预览卡片。灯泡与麦克风使用同组中性工具色；停止操作使用与发送相同的主操作颜色和 36 dp 圆形表面，实心方块区分操作。API 35 隔离测试包以模拟会话验证无建议、有草稿查看、阅读态填入和采纳后隐藏，以及浅深色停止后回到发送。未在用户真机或 TalkBack 下实测。

## fix107 自动建议与固定灰阶主题

自动预览在输入栏同一表面内显示，摘要可点开阅读全文；「填入」和全文中的「填入输入框」使用聊天文字色。实际迁移检查使用 API 35 聊天页，延迟送达短建议、长建议及键盘输入期间的建议。短建议占用从 196 px 降至 108 px（同一模拟器），浏览历史时检查了建议送达前后的消息坐标。浅色普通和遗留蓝色设置中，摘要操作与全文操作取到 #171715，深色为 #F1F0EC。默认与遗留蓝色的输入栏、全文弹层抽样区域逐像素相同。外观页已移除主题色入口，保留浅深色、语言、字体和消息气泡。全局 Compose 颜色固定为单色。用户真机和 TalkBack 未实测。

## fix108 输入框焦点

输入栏外层 Surface 固定使用中性细边，编辑焦点交给文本框和光标表达。API 35 隔离测试包在浅色、深色分别核对了未编辑、输入中、收起键盘后的外沿像素，三种状态均保留同色单像素边缘，返回键收起键盘后草稿仍在。Release 单测及发布 lint 通过。用户真机和 TalkBack 未实测。

## fix109 建议入口与底部执行状态

建议入口使用展开输入框第二行右侧的原生 IconButton，48 dp 触控区，有建议才显示。点开全文后手动填入，已有草稿可查看。API 35 模拟器验证了浅深色的长短建议、草稿保护、翻阅历史时的消息坐标，以及入口出现前后输入框与左侧模型工具的位置。底部运行状态随当前轮次显示，模拟器覆盖了阶段性回复后的等待、工具执行、流式回复、无消息的活跃会话与停止。发布单测和发布 lint 通过。用户真机、大字体及 TalkBack 未实测。
