使用 RemodexTheme 的颜色角色和用户的字体偏好。默认使用内置对话灰，跟随系统和自选种子色使用对应的浅深色方案。状态提示沿用相应的语义色。先用项目解析到的 Material 3 API 核对组件签名。版本检查和构建通过仓库的 scripts/build-android.sh 执行。

- 优先使用语义相符的原生组件及默认颜色、焦点、按压、禁用和命中区。需要覆盖背景时同时核对内容色，例如 primary/onPrimary、errorContainer/onErrorContainer。让子图标和文字继承组件提供的内容色。
- 保留聊天草稿、光标、附件单击与长按、发送与停止、侧栏切换和历史滚动位置。使用选中、切换、进度、按钮等无障碍语义表达业务状态。检查相邻动作的触控范围。
- 代码、差异、终端和消息媒体可以保留领域渲染。复用主题字阶、色彩和交互约定。修改窗口边距前先追踪 Activity、Scaffold、弹层和 IME 各自消费的 inset。
- 在浅色、深色、大字体下操作修改过的组件。用 TalkBack 核对朗读与焦点，用有代表性的 release 构建测聊天滚动和流式更新。记录测试包、设备、已验证状态和遗留项。
- 每批更新[组件迁移清单](references/component-migration.md)，记录实际入口、选择理由和验收结果。保留构建工具、依赖、页面三批的独立验证记录。
